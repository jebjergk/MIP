# Glossary and concept map

| Term | Meaning |
|------|---------|
| Maturity stage | Evidence depth for a pattern/symbol context |
| Trust gate | Qualification for production-style reliance |
| Committee stance | Structured multi-input posture for a symbol |
| Proposal | Executable order package derived from a decision path |
| Viability | Pre-trade checks for realism and risk |
| Parallel Worlds | Interpretive scenario context — informative, not sole gate |
